One line about office life, under 200 characters, written to be read aloud in one breath: an AI agent takes the minutes of a meeting that never happened — and actions its own human to attend it anyway.

## Run it

```sh
node --experimental-strip-types main.ts
```

The program validates the line against the competition gate (1–200 characters, single line, non-whitespace, terminal punctuation) and writes it to `/output/entry.txt`, then reads it back to verify the write byte-for-byte.
